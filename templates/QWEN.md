# Templates Directory - QWEN.md

## 目录概述

`templates/` 目录存储从 Wondershare PDFelement 官方模板库下载的 PDF 文档模板。这些模板可用于创建各类商务文档、表单和印刷材料。

**来源**: https://pdf.wondershare.jp/templates/

**下载日期**: 2026 年 3 月 24 日

## 模板分类说明

### 📄 发票类 (invoices/)
- **invoice-standard.pdf** - 标准发票格式
- **invoice-bank.pdf** - 含银行转账信息的发票
- **invoice-blue/gray/orange/snow.pdf** - 不同设计风格的发票
- **invoice-english2.pdf** - 英文版发票

### 📋 收据类 (receipts/)
- **receipt-02.pdf** - 标准收据
- **receipt-item-vertical.pdf** - 竖版物品明细收据

### 💰 报价单 (quotes/)
- **quotation-8.pdf** - 标准报价单格式

### 📦 订单类 (orders/)
- **purchase-order4.pdf** - 采购订单

### 📠 传真 (fax/)
- **fax03.pdf** - 标准传真封面

### 📊 报告 (reports/)
- **report-weekly.pdf** - 周报模板

### 📝 简历 (resume/)
- **resume-jis.pdf** - 日式标准简历 (JIS 规格)

### 📑 会议纪要 (minutes/)
- **minutes-03.pdf** - 会议纪要格式 A
- **minutes-06.pdf** - 会议纪要格式 B

### 📜 合同 (contracts/)

### 📮 其他商务文档 (business/ 根目录)

## 使用方法

### 查看 PDF
```bash
# Linux (需要 PDF 阅读器)
evince templates/business/invoices/invoice-standard.pdf

# macOS
open templates/business/invoices/invoice-standard.pdf
```

### 编辑 PDF
推荐使用以下软件：
- **PDFelement** - Wondershare 官方编辑器
- **Adobe Acrobat Pro** - 专业 PDF 编辑
- **LibreOffice Draw** - 免费开源替代

### 打印
直接打开 PDF 文件并使用系统默认打印机打印。
