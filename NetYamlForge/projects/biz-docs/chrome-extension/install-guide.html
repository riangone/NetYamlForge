🤖 BizDocs AI Assistant — 安装说明

本扩展通过 antigravity CLI 调用 AI，需要安装 Native Messaging Host 才能正常工作。

前置条件

1 安装 antigravity CLI（参考其官方文档）
安装后确认可以在终端运行： 
antigravity --version
2 确认 Python 3 已安装： 
python3 --version

安装 Native Messaging Host

3 在 chrome://extensions 页面开启开发者模式，记下扩展 ID（类似 abcdefghijklmnopabcdefghijklmnop）
4 在终端进入扩展目录的 native/ 文件夹，运行安装脚本： 
cd /path/to/chrome-extension/native
chmod +x install.sh
./install.sh <你的扩展ID>
5 回到 chrome://extensions 点击重新加载扩展
6 打开任意 BizDocs 页面（如 http://localhost:5000/biz-docs/Dashboard），点击右侧 🤖 按钮开始使用

自定义 antigravity 命令（可选）

创建配置文件 ~/.config/bizdocs-ai/config.json：

{
  "command": "antigravity",
  "args": ["run", "--prompt"],
  "timeout": 90
}
提示：如果连接状态仍显示错误，请检查终端日志。 在 macOS 上，Native Messaging Host 日志可在 Console.app 中查看。
