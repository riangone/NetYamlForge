# My Home (userhome)

> ユーザー個人ホームページを提供するサブプロジェクトです。

## 概要

`userhome` は、認証済みユーザーがログイン後に最初に目にする個人用ダッシュボードです。

- ユーザー情報（表示名、ユーザータイプ、ロール）の表示
- アクセス可能なプロジェクト一覧とデフォルトプロジェクトの設定
- クイックアクション（タスク、ドキュメント、通知、設定）

## ディレクトリ構成

```
userhome/
├── project.yaml          # プロジェクト設定
├── dashboard.yml         # ダッシュボード設定
├── config/
│   ├── home-page.yml     # ホームページ表示設定
│   ├── layout.yml        # ナビゲーション設定
│   └── i18n.yml          # 翻訳キー
└── docs/
    └── README-ja.md      # このファイル
```
