# 週次運用シート

## 毎週の固定進行

### 月曜
1. 今週の優先タスクを3-5件確定
2. 各タスクの担当（Human/AI）を割当
3. 依存順序を確認

### 水曜
1. 中間レビュー
2. ブロッカー解消
3. スコープ逸脱の補正

### 金曜
1. 完了判定（DoD確認）
2. KPI更新
3. 次週候補の棚卸し
