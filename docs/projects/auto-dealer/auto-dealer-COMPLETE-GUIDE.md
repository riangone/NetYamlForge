## システム概要

### 基本情報

| 項目 | 内容 |
|------|------|
| **システム名** | CustomerAI（自動車ディーラー AI 窓口システム） |
| **目的** | AI 技術による 24/7 自動化カスタマーサポート |
| **対象** | 自動車ディーラー（販売・サービス・整備） |
| **チャネル** | Web チャット、LINE、Email |
| **コア機能** | 自動応答、予約受付、智能転接、感情分析 |

### 核心价值

| 価値 | 説明 |
|------|------|
| **24/7 可用性** | 営業時間外も自動応答 |
| **コスト削減** | 単純問合せの自動化（目標 80%） |
| **顧客体験向上** | 即時応答、迅速な予約 |
| **データ蓄積** | 完全な対話履歴の記録 |
| **精密転接** | 適切な担当者への自動ルーティング |

## 業務フローとシナリオ

### シナリオ 1: 顧客がサービス予約を行う（AI 自動応答）

**ユーザー**: 顧客（田中様）  
**チャネル**: Web チャット  
**結果**: AI 自動処理（オペレーター関与なし）

```
[10:15] 顧客：「来週のオイル交換の予約をしたいです」
            ↓
[10:15] AI: 「承知いたしました。オイル交換の予約ですね。
            以下の候補からご希望の日時をお選びください。」
            
            【AI の内部処理】
            1. 意図認識：「service_appointment」
            2. 置信度：0.92（高）
            3. 感情スコア：0.1（中立）
            4. 必要情報：日時、車種、メニュー
            ↓
[10:16] AI: 「来週の火曜日〜金曜日の午前中が空いております。
            どちらがよろしいでしょうか？」
            
            [表示：予約候補ボタン]
            [3/31(火) 10:00] [3/31(火) 11:00]
            [4/1(水) 10:00] [4/2(木) 14:00]
            ↓
[10:17] 顧客：「3/31(火) 10:00 でお願いします」
            ↓
[10:17] AI: 「承知いたしました。
            田中様のお車（カムリ）のオイル交換を
            3 月 31 日（火）10:00 に予約いたしました。
            
            予約番号：APPT-20260331-001
            
            ご予約変更・キャンセルは
            本メッセージにご返信ください。」
```

### シナリオ 2: 複雑な問い合わせ（AI→人間転接）

**ユーザー**: 顧客（佐藤様・VIP 顧客）  
**チャネル**: LINE  
**結果**: オペレーターに転接

```
[14:23] 顧客：「先日納車された車のエンジンから
            異音がするのですが、どうすればいいですか？」
            ↓
[14:23] AI: 「ご迷惑をおかけして誠に申し訳ございません。
            直ちに担当の者にお繋ぎいたしますので、
            少々お待ちください。」
            
            【AI の内部処理】
            1. 意図認識：「complaint」（苦情）
            2. 置信度：0.45（低）
            3. 感情スコア：-0.65（強い不満）
            4. 顧客ランク：VIP
            5. 転接判断：⚠️ 即時転接
            6. 優先度：高
            7. 対象部門：service（サービス）
            ↓
[14:23] システム：
            「オペレーターの山田に接続しました。
            しばらくお待ちください。」
            
            【オペレーター画面に表示】
            ┌─────────────────────────────────┐
            │ 🔴 VIP 顧客 - 優先度高           │
            │ 顧客：佐藤様（VIP）              │
            │ 車両：インプレッサ（新車納車 3 日）│
            │ 件名：エンジン異音               │
            │ 感情：😠 不満                   │
            │ 前回の対話：[リンク]             │
            └─────────────────────────────────┘
```

#### 2. AI 分析レポート (`/Page/AIAnalytics`) ⭐ NEW

**AI 性能 KPI** (6 件):
- 総対話数（7 日間）
- AI 自動解決数
- 平均置信度
- エスカレーション率
- 平均満足度

- 意図認識分析（top 10）（bar）

## 付録

### データモデル（主要エンティティ）

```yaml
entities:
  - ai_conversations      # AI 対話セッション
  - ai_messages           # AI メッセージ
  - ai_handovers          # AI エスカレーション
  - ai_feedback           # AI フィードバック
  - ai_knowledge          # AI 知識ベース
  - customers             # 顧客マスタ
  - vehicles              # 車両マスタ
  - service_appointments  # サービス予約
  - service_requests      # サービスリクエスト
```

### バッチジョブ（自動化タスク）

| ジョブ名 | 実行時間 | 説明 |
|---------|---------|------|
| `daily_conversation_stats` | 毎日 23:00 | AI 対話統計収集 |
| `appointment_reminder` | 毎日 10:00 | 翌日予約リマインド |
| `vip_customer_followup` | 毎週月曜 9:00 | VIP 顧客フォローアップ |

### フック（ビジネスロジック）

| フック名 | 対象エンティティ | 説明 |
|---------|----------------|------|
| `validate_customer_phone` | customers | 電話番号形式検証 |
| `normalize_customer_name` | customers | 顧客名正規化 |
| `validate_ai_conversation` | ai_conversations | 対話検証 |
| `validate_appointment_date` | service_appointments | 予約日検証 |
| `validate_appointment_time` | service_appointments | 予約時間検証 |
