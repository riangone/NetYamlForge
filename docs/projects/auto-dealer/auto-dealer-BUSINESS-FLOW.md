# auto-dealer-demo 業務フローとユーザーシナリオ

## 概要

本ドキュメントは、自動車ディーラー AI 窓口システムの実業務での使用方法を、具体的なユーザーシナリオと业务流程図で説明します。

---

## ユーザーロールとアクセス権限

### システム利用者一覧

| ロール | 説明 | 主な機能 |
|-------|------|---------|
| **顧客（一般）** | 自動車購入・サービス利用の一般顧客 | Web チャット、LINE、Email で AI と対話 |
| **顧客（VIP）** | 特別顧客（プラチナ・VIP ランク） | 優先的人工転接、専任担当者 |
| **Web 訪問者** | 未登録のウェブサイト訪問者 | 簡易問合せ、リード情報収集 |
| **オペレーター** | AI 転接された人間客服 | 対話ダッシュボード、キュー管理 |
| **サービス担当** | サービス・整備受付担当 | 予約管理、作業指示 |
| **販売担当** | 新車・中古車販売担当 | 顧客管理、見積作成 |
| **管理者** | システム管理者 | AI 学習データ管理、設定 |

## シナリオ 1: 顧客がサービス予約を行う（AI 自動応答）

### ユーザー：顧客（田中様）
### チャネル：Web チャット

```
[10:15] 顧客：「来週のオイル交換の予約をしたいです」
            ↓
[10:15] AI: 「承知いたしました。オイル交換の予約ですね。
            以下の候補からご希望の日時をお選びください。」
            
            【AI の内部処理】
            1. 意図認識：「service_appointment」
            2. 置信度：0.92（高）
            3. 感情スコア：0.1（中立）
            4. 必要情報：日時、車種、メニュー
            ↓
[10:16] AI: 「来週の火曜日〜金曜日の午前中が空いております。
            どちらがよろしいでしょうか？」
            
            [表示：予約候補ボタン]
            [3/31(火) 10:00] [3/31(火) 11:00]
            [4/1(水) 10:00] [4/2(木) 14:00]
            ↓
[10:17] 顧客：「3/31(火) 10:00 でお願いします」
            ↓
[10:17] AI: 「承知いたしました。
            田中様のお車（カムリ）のオイル交換を
            3 月 31 日（火）10:00 に予約いたしました。
            
            予約番号：APPT-20260331-001
            
            ご予約変更・キャンセルは
            本メッセージにご返信ください。」
            
            【AI の内部処理】
            1. AppointmentService.CreateAppointment()
            2. 顧客データベース更新
            3. 予約確定 Email 送信
            4. 顧客カレンダーに追加
```

### 結果
- ✅ 予約完了（AI 自動処理）
- ✅ 顧客は待ち時間ゼロ
- ✅ オペレーターは関与せず

### 意図認識ルール例

```yaml
intent_rules:
  service_inquiry:
    keywords:
      - "オイル交換"
      - "車検"
      - "整備"
      - "予約"
    patterns:
      - "{service_type} の予約をしたい"
      - "{date} は空いていますか"
    confidence_threshold: 0.7
    
  price_quote:
    keywords:
      - "価格"
      - "見積"
      - "いくら"
      - "値引き"
    patterns:
      - "{car_model} の価格を教えてください"
      - "値引きはできますか"
    confidence_threshold: 0.75
    
  complaint:
    keywords:
      - "不満"
      - "怒り"
      - "困る"
      - "ひどい"
    sentiment_threshold: -0.3  # 感情スコアがこれ以下なら即時転接
    confidence_threshold: 0.5  # 低く設定し、少しでも疑わしければ転接
```
