## 1. 系统愿景与定位

`auto-dealer-demo` 是一个基于 **AI 全面主导 (AI-Led)** 理念构建的汽车销售管理系统。

### 1.1 核心转变
*   **传统模式**：人类录入数据 -> 人类分析 -> 人类执行 -> 系统记录。
*   **AI 主导模式**：AI 自动获取线索 -> AI 评分决策 -> AI 自动执行触达 -> **人类仅在低置信度或高风险时介入确认**。

### 1.2 目标指标
*   **自动化率**：力争将 90% 的常规客户培育和报价工作自动化。
*   **响应速度**：实现秒级的初步线索评分和分钟级的个性化邮件触达。

## 2. 系统架构 (System Architecture)

系统采用 **“决策-执行-反馈”** 的闭环架构：

### 2.1 核心组件
1.  **AI 决策引擎 (AiDealerEngineExecutor)**: 
    *   定期扫描数据库中的“冷线索”和“热机会”。
    *   调用 Gemini CLI 进行推理，生成评分、培育建议和报价单。
2.  **自动通讯引擎 (AiCommunicationExecutor)**:
    *   将 AI 的决策转化为具体的邮件或 LINE 消息。
    *   自动生成个性化正文，并处理发送逻辑。
3.  **智能交互 UI 层 (Smart UI)**:
    *   为销售和管理人员提供“AI 朝会”、“决策审批中心”等专门视图。

### 2.2 数据流向
`数据输入` -> `SQL 提取候选` -> `Gemini 推理` -> `置信度过滤` -> `(自动执行 | 人工审批)` -> `执行动作 (邮件/更新)` -> `记录日志`

## 3. 功能模块详细说明

### 3.1 AI 智能决策模块
*   **线索评分 (Lead Scoring)**: 每2小时运行，自动对沉默客户重新评分，识别潜在回流机会。
*   **任务生成 (Nurturing Task)**: 每日 08:00 运行，根据评分生成“试驾邀请”、“发送参数”等具体行动。
*   **自动报价 (Quote Generation)**: 针对高分线索，自动计算折扣、月供及首付。

### 3.2 自动通讯模块
*   **自动邮件发送**: 自动处理 AI 生成的培育邮件和报价邮件。
*   **无响应追踪**: 自动检测 3 天未回复的邮件，并生成后续的补救跟进任务。

### 3.3 人工介入机制 (Human-in-the-Loop)
系统设定了严格的自动执行边界：
*   **自动执行阈值**: 置信度 (Confidence) ≥ 85% (评分) / 80% (邮件) / 90% (报价)。
*   **强制人工审批**: 折扣率 > 10%、预算 > 500万、或客户存在“抱怨/投诉”关键词。

## 4. UI 交互与用户指南

### 4.1 销售代表 (Sales Rep) 工作流
1.  **AI 朝会 (Morning Assembly)**: 每天登录 `SalesRepDashboard`，查看顶部 AI 推荐的今日 Top 5 必做任务。
2.  **推荐行动**: 在线索列表中，直接点击 AI 推荐的按钮（如“发送优惠券”）即可触发后续流程。
3.  **AI 助手**: 在 `AiAssistant` 页面实时监控 AI 正在为您处理的任务量。

### 4.2 销售经理 (Sales Manager) 工作流
1.  **决策审批**: 定期访问 `AiDecisionApproval` 页面。
2.  **红色警报**: 优先处理页面顶部的“紧急审批”项（通常是高折扣或关键投诉）。
3.  **批量操作**: 对高确信度的 AI 建议进行一键批量承认。

### 4.3 客户 (Customer) 体验
1.  **AI 私人顾问**: 客户在 `CustomerAiChat` 页面可以看到 AI 自动发送的所有提案。
2.  **自助服务**: 客户可以通过 AI 交互界面自助预约保养或查询贷款进度。
