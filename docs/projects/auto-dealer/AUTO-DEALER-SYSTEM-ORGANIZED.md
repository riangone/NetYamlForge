## 🎯 主要機能モジュール（8個）

### 1. **顧客管理** 👥
- 顧客基本情報の登録・更新（氏名、連絡先、住所）
- 顧客区分管理（見込み客、契約済み、リピーターなど）
- 販売・サービス履歴の統合参照

**データ構造:**
| 項目 | 説明 |
|------|------|
| 顧客ID | 主キー |
| 氏名 | 姓・名（全角20文字以内） |
| フリガナ | セイ・メイ（カタカナ） |
| 電話番号 | 必須（15文字以内、数字とハイフン） |
| メール | 任意（100文字以内） |
| 住所 | 郵便番号、都道府県、市区町村以下 |
| 顧客区分 | 見込、契約済、リピーターなど |
| 登録日 | システムが自動生成 |

---

### 2. **車両在庫管理** 🚗
- 新車・中古車の一元管理
- 在庫登録（車種、グレード、年式、走行距離、価格）
- 入庫・出庫・納車履歴の追跡

**車両テーブルの主要項目:**
- 車両ID（主キー）
- 車種・グレード・年式・走行距離
- 仕入価格・売却予定価格
- ステータス（在庫中、予約、納車済み）
- 入庫日・在庫状況

---

### 3. **販売管理** 📝
販売フロー: 顧客登録 → 見積作成 → 契約 → 納車準備 → 納車

#### 見積書作成
- 必須項目: 見積日、有効期限、顧客ID、車両ID
- 自動採番: 見積番号
- 含まれるもの: オプション、保険、下取り、ローン条件
- 出力: PDF可能、改訂履歴管理

#### 契約書作成
| 項目 | 必須 | 制約 |
|------|------|------|
| 契約番号 | 自動採番 | 編集不可 |
| 契約日 | ✓ | YYYY-MM-DD、未来日禁止 |
| 契約金額 | ✓ | 0以上の整数 |
| 支払方法 | ✓ | 一括、ローン等から選択 |
| 頭金 | 任意 | 契約金額以下 |
| ローン金額 | 任意 | 契約金額以下 |
| 金融機関名 | 任意 | 50文字以内 |
| 納車予定日 | ✓ | 契約日以降 |

#### 納車管理
- 進捗状態: 車検申込 → 車検完了 → 登録手続き → 納車可能 → 納車済み
- 記録項目: 納車日時、納車担当者、顧客署名
- アフターフォロー: 納車後1週間・1ヶ月のタスク自動生成

---

### 4. **サービス・整備管理** 🔧

**受付フロー:** 予約/当日受付 → 顧客検索 → 作業指示書作成 → 進捗管理 → 請求 → 納車

#### 受付・予約管理
- 予約受付: 希望日時、作業内容（点検、修理、車検など）
- 当日受付: 受付時刻と作業内容を登録
- 履歴参照: 過去のサービス履歴を即座に確認

#### 作業指示書
| 内容 | 説明 |
|------|------|
| 作業内容 | 詳細記録 |
| 必要部品 | リストアップ＆自動引当 |
| 作業時間 | 見積もり設定 |
| 担当者割当 | 整備士の指定 |

#### 進捗ステータス
```
受付済み → 作業中 → 完了 → 納車待ち → 納車済み
```

#### 点検・整備履歴
- 次回点検時期の自動算出（走行距離・日数ベース）
- 定期点検スケジュール管理
- 顧客別・車両別の履歴一覧表示

---

### 5. **部品管理** ⚙️

**在庫管理フロー:** マスタ登録 → 入庫 → 出庫/使用 → 在庫調整 → 発注

#### 部品マスタ登録
| 項目 | 説明 |
|------|------|
| 部品コード | 主キー（最大20文字） |
| 部品名 | 最大100文字 |
| メーカー名 | 最大50文字 |
| 仕入価格 | 数値（整数） |
| 販売価格 | 数値（整数） |
| 在庫数 | 自動更新 |
| 発注点 | アラート閾値 |
| 安全在庫数 | 最小保有数 |

#### 入出庫管理
- **入庫:** 入荷伝票番号、入荷日、数量、単価を記録
- **出庫:** サービス使用時に自動減算、使用記録を保持
- **調整:** 棚卸しによる実在庫とシステム在庫の差異を調整

#### インベントリアラート
- 在庫が発注点を下回った場合、即座にアラート表示
- 在庫回転率、在庫金額レポート
- 発注頻度の分析

---

### 6. **会計・請求管理** 💰

#### 請求書作成
- 販売請求: 車両代金 + オプション + 手数料
- サービス請求: 作業料金 + 部品代金 + 消費税（自動計算）
- 部品販売請求: 部品代金 + 消費税

#### 入金管理
- 入金登録: 入金日、金額、支払方法を記録
- 未入金一覧: 期限切れ請求書を監視
- 頭金・中間金・残金の分割管理

#### 売上集計
- **日次集計:** 本日の売上サマリー
- **月次集計:** 月間売上、部門別売上、担当者別売上
- **年間集計:** 年間売上推移

---

### 7. **レポート・分析** 📊

| レポート種類 | 内容 |
|-------------|------|
| 販売レポート | 販売台数、売上、部門別・担当者別集計 |
| サービスレポート | サービス売上、作業実績、完了率 |
| 顧客分析 | 顧客別売上、リピート率、購買履歴 |
| 在庫レポート | 在庫回転率、在庫金額、発注分析 |

**出力形式:** CSV, PDF対応

---

### 8. **マスタ管理** ⚙️（管理者用）

#### マスタデータ一覧
- 車種マスタ（車種名、型式、グレード）
- グレードマスタ（グレード名、標準装備）
- 部品マスタ（部品コード、名称、価格）
- 顧客区分マスタ（見込、契約済、リピーターなど）
- 作業内容マスタ（点検、修理、車検など）

#### ユーザー権限管理
| 権限レベル | 権限内容 |
|-----------|--------|
| 管理者 | 全機能、マスタ管理、権限設定 |
| 販売担当 | 顧客、車両、見積、契約管理 |
| サービス担当 | 受付、作業指示、進捗管理 |
| 部品担当 | 部品在庫、発注管理 |
| 受付 | 受付・予約管理、顧客照会 |
| 経理 | 請求、入金、レポート参照 |

## 🔄 主要ビジネスフロー

### フロー1: 販売契約フロー（契約から納車まで）

```
1. 顧客情報登録／照会
   ↓
2. 車両選定・見積作成
   ├─ 見積番号自動採番
   ├─ オプション・下取り・ローン条件を含める
   └─ PDF出力可能
   ↓
3. 見積提示・交渉
   ├─ 改訂履歴管理（複数回対応）
   └─ 交渉メモ記録
   ↓
4. 契約書作成
   ├─ 契約番号自動採番
   ├─ 顧客署名（紙または電子署名）
   └─ 金融機関情報記録
   ↓
5. 入金・ローン手続き
   ├─ 頭金・中間金・残金管理
   └─ ローン申込日、承認日記録
   ↓
6. 納車準備
   ├─ 車検・登録・点検進捗管理
   └─ 納車日時予約
   ↓
7. 納車
   ├─ 在庫ステータス更新（「納車済み」）
   └─ 納車確認記録
   ↓
8. アフターフォロー
   ├─ 1週間・1ヶ月フォローアップタスク自動生成
   └─ 顧客満足度アンケート
```

### フロー2: サービス受付フロー（受付から納車まで）

```
1. 受付・予約
   ├─ 予約受付：希望日時、作業内容入力
   └─ 当日受付：受付時刻、作業内容登録
   ↓
2. 作業指示書作成
   ├─ 作業内容詳細記録
   ├─ 必要部品リストアップ＆自動引当
   └─ 作業時間見積もり
   ↓
3. 作業進捗管理
   ├─ ステータス: 受付済み → 作業中 → 完了 → 納車待ち → 納車済み
   ├─ 担当者（整備士）割当
   └─ 開始・終了時刻記録
   ↓
4. 部品使用・在庫更新
   ├─ 実績部品を登録
   ├─ 在庫から自動減算
   └─ 部品不足時は発注フラグ
   ↓
5. 請求書作成
   ├─ 作業料金 + 部品代金 + 消費税（自動計算）
   └─ PDF出力可能
   ↓
6. 入金・納車
   ├─ 入金確認後に納車処理
   └─ 車両引き渡し記録
   ↓
7. 履歴管理
   ├─ 次回点検時期の自動算出
   └─ 顧客別・車両別の履歴一覧
```

### フロー3: 部品在庫管理フロー

```
1. 部品マスタ登録
   └─ 部品コード、名称、仕入価格、販売価格、発注点等
   ↓
2. 入庫管理
   ├─ 入荷伝票番号、入荷日、数量、単価を記録
   └─ 在庫数を更新
   ↓
3. 出庫管理
   ├─ サービス使用、販売による出庫を記録
   └─ 在庫数から自動減算
   ↓
4. 在庫照会・検索
   ├─ 部品コードまたは名称で検索
   └─ 発注点を下回った場合にアラート表示
   ↓
5. 発注管理
   ├─ 在庫が発注点以下の部品を一覧表示
   ├─ 発注先、発注数量、希望納期を設定
   └─ 発注履歴を管理
   ↓
6. 在庫調整
   ├─ 棚卸しによる実在庫とシステム在庫の差異を調整
   └─ 調整理由を記録
   ↓
7. レポート
   └─ 在庫回転率、在庫金額、発注頻度分析
```

## 🔐 トランザクション管理

### 販売契約フロー
| ステップ | トランザクション | ロールバック条件 |
|---------|-----------------|-----------------|
| 見積作成 | 見積レコード作成 | 入力エラー、ユーザーキャンセル |
| 契約書作成 | 契約レコード作成、在庫ステータス更新 | 契約番号採番エラー |
| 納車処理 | 在庫ステータス「納車済み」へ更新、納車履歴作成 | 納車日時エラー |

### サービス受付フロー
| ステップ | トランザクション | ロールバック条件 |
|---------|-----------------|-----------------|
| 作業指示書作成 | 作業指示レコード作成、部品引当 | 部品不足、在庫不一致 |
| 部品実績登録 | 部品出庫レコード作成、在庫減算 | 在庫不足、部品コード不一致 |
| 請求書作成 | 請求レコード作成、売上計上 | 金額計算エラー |

### 部品在庫管理フロー
| ステップ | トランザクション | ロールバック条件 |
|---------|-----------------|-----------------|
| 入庫処理 | 部品入庫レコード作成、在庫増加 | 数量エラー、部品コード不一致 |
| 出庫処理 | 部品出庫レコード作成、在庫減算 | 在庫不足 |
| 在庫調整 | 調整レコード作成、在庫更新 | 調整理由未入力 |

**共通ルール:**
- ACID特性を保証（全ステップが成功して初めて確定）
- エラー発生時は全ての変更をロールバック
- 監査ログ（操作者、操作内容、日時、結果）を記録

## 🤖 AI窓口システム設計（将来像）

### 概要
顧客からの問い合わせを AI が自動処理し、複雑な案件のみ人間の担当者に引き継ぐシステム。

### 機能
1. **自動応答:** 営業時間外やピーク時の問い合わせに自動対応
2. **FAQ参照:** 一般的な質問（営業時間、点検時期など）を自動回答
3. **予約受付:** 「来週の月曜日に点検したい」のような自然言語での予約
4. **顧客情報統合:** 顧客IDから過去の履歴を即座に参照可能
5. **人間への引き継ぎ:** 複雑な案件は自動的に担当者にルーティング

### インテグレーション
- LLM（ChatGPT、Claude等）による自然言語処理
- LINE、メール、チャットボット等を統一インターフェースで管理
- 顧客対応の履歴を全て保持（データの一元管理）
