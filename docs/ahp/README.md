## Quick Summary

```
電話   → 電話番号
メール → メールアドレス
Web    → URL
AI     → AI Handshake Protocol (AHP)
```

AHP は **Identity（誰か）+ Intent（何をしたいか）+ Permission（何を任せるか）** の三元組で、AI エージェント同士の初回接触を標準化する。
