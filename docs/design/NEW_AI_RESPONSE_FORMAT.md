# ✅ AI 応答フォーマット - 新ルール適用完了

## 📋 新ルール概要

AI の応答フォーマットが以下のルールに従うように更新されました：

### 共通事項
- ✅ **件数と概要（サマリ）のみを表示する**
- ✅ **各レコードは簡潔な情報**（名前・ステータス・日時・価格など）に留める
- ✅ **詳細データは含めない**（住所・メモ・備考・全フィールド羅列など）
- ✅ **各項目に詳細ページへの Markdown リンクを追加**

### エンティティ別表示内容

#### customers（顧客マスタ）
- **メイン情報**: 名前
- **ステータス**: 顧客ランク（VIP/GOLD/SILVER/一般）
- **追加情報**: 最終来店日、電話番号
- **リンク**: 顧客詳細ページ

#### vehicles（車両在庫）
- **メイン情報**: 年式 + ブランド + モデル
- **ステータス**: 販売中/商談中/売約済
- **追加情報**: 価格、走行距離
- **リンク**: 車両詳細ページ

#### service_appointments（予約）
- **メイン情報**: 予約タイプ（試乗/サービス/相談）
- **ステータス**: 未確認/確定/完了/キャンセル
- **追加情報**: 希望日
- **リンク**: 予約詳細ページ

#### sales_leads（営業リード）
- **メイン情報**: リード ID
- **ステータス**: 新規/進行中/成約/失注
- **追加情報**: 興味のある車両、作成日
- **リンク**: リード詳細ページ

## 📝 実装コード例

### FormatAsMarkdown メソッド
```csharp
public string FormatAsMarkdown(
    List<IDictionary<string, object?>> data,
    ParsedQueryParams? query = null,
    int? total = null,
    string? project = null)
{
    if (data.Count == 0)
    {
        return "該当件数：0 件\n\n条件に一致するデータはありませんでした。";
    }

    var sb = new StringBuilder();

    // 件数表示
    var totalCount = total ?? data.Count;
    sb.AppendLine($"該当件数：{totalCount} 件");
    sb.AppendLine();

    // 各レコードの概要表示（詳細リンク付き）
    foreach (var row in data)
    {
        var summary = FormatRecordSummary(entity, row, keyField, project);
        sb.AppendLine(summary);
    }

    return sb.ToString().TrimEnd();
}
```
