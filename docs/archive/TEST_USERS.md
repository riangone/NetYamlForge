## 登录方式

1. **访问登录页面**：`http://localhost:5000/{project}/Account/Login`
   - 例如：`http://localhost:5000/auto-dealer-demo/Account/Login`
   - 例如：`http://localhost:5000/framework/Account/Login`

2. **输入凭据**：
   - 用户名：上表中的 `用户名` 列
   - 密码：`Test@123!`（所有测试用户统一密码）

3. **登录后重定向**：系统会根据用户角色自动重定向到对应的仪表板页面
