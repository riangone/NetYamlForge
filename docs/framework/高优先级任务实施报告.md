### ✅ 任务 2: 集成 ToolValidator 到 AutoDealerChatService

**文件**: `Services/AI/AiToolOrchestrator.cs` (新建)

**设计思路**:
为了避免修改庞大的 AutoDealerChatService (1546 行),创建了一个独立的编排服务作为中间层。

**功能**:
1. **Tool 验证**: 使用 ToolCallValidator 进行三重验证
2. **状态检查**: 验证 Tool 调用是否符合当前 FSM 状态
3. **执行编排**: 验证通过后执行 Tool,失败时返回详细错误信息
4. **审计日志**: 记录所有 Tool 调用及其结果

**接口定义**:
```csharp
public interface IAiToolOrchestrator
{
    Task<ToolExecutionResult> ValidateAndExecuteToolAsync(
        JsonNode toolCall,
        string conversationId,
        string projectId,
        CancellationToken ct = default);

    Task<SessionStateInfo> GetSessionStateAsync(string conversationId);
}
```

**验证流程**:
```
LLM 输出 Tool 调用
    ↓
[1] 获取当前 FSM 状态
    ↓
[2] ToolCallValidator.ValidateAsync()
    ├── JSON Schema 校验
    ├── Entity/Action 白名单
    └── SqlSafetyGuard 标识符过滤
    ↓
[3] FSM 状态允许性检查
    ↓
[4] 执行 Tool
    ↓
[5] 记录审计日志
    ↓
返回结果
```

**使用示例**:
```csharp
// 在 AutoDealerChatService 或其他地方注入
public class AutoDealerChatService
{
    private readonly IAiToolOrchestrator _toolOrchestrator;
    
    public async Task<ChatResponse> ProcessMessageAsync(string conversationId, string message)
    {
        // ... LLM 返回 Tool 调用 ...
        
        var result = await _toolOrchestrator.ValidateAndExecuteToolAsync(
            toolCallJson,
            conversationId,
            projectId);
        
        if (!result.IsSuccess)
        {
            // 返回验证错误给 LLM,让其重新输出
            return ChatResponse.Error(result.ErrorMessage);
        }
        
        // ... 继续处理 ...
    }
}
```

```csharp
// 在 Program.cs 中添加
builder.Services.AddHttpClient<ILlmProvider, CliFirstLlmProvider>()
    .AddPolicyHandler(GetRetryPolicy())
    .AddPolicyHandler(GetCircuitBreakerPolicy())
    .AddPolicyHandler(GetTimeoutPolicy());

static IAsyncPolicy<HttpResponseMessage> GetRetryPolicy()
{
    return HttpPolicyExtensions
        .HandleTransientHttpError()
        .WaitAndRetryAsync(3, retryAttempt => 
            TimeSpan.FromSeconds(Math.Pow(2, retryAttempt)));
}

static IAsyncPolicy<HttpResponseMessage> GetCircuitBreakerPolicy()
{
    return HttpPolicyExtensions
        .HandleTransientHttpError()
        .CircuitBreakerAsync(5, TimeSpan.FromSeconds(60));
}

static IAsyncPolicy<HttpResponseMessage> GetTimeoutPolicy()
{
    return Policy.TimeoutAsync<HttpResponseMessage>(8);
}
```

## 五、使用指南

### 5.1 在对话服务中集成 FSM

```csharp
public class MyChatService
{
    private readonly ISlotFillingManager _slotFilling;
    private readonly IAiToolOrchestrator _toolOrchestrator;
    
    public async Task<ChatResponse> ProcessUserMessageAsync(
        string conversationId, 
        string userMessage,
        double intentConfidence)
    {
        // 1. 更新 FSM 状态 (基于意图置信度)
        if (intentConfidence < 0.6)
        {
            await _slotFilling.UpdateFsmStateAsync(
                conversationId, 
                AppointmentStateMachine.Trigger.LowConfidence,
                intentConfidence);
        }
        
        // 2. 检查是否进入 ESCALATE 状态
        var currentState = await _slotFilling.GetCurrentFsmStateAsync(conversationId);
        if (currentState == AppointmentStateMachine.State.Escalate)
        {
            return ChatResponse.Escalate("已转接人工客服");
        }
        
        // 3. 处理 Tool 调用
        if (llmResponse.HasToolCall)
        {
            var isAllowed = await _slotFilling.IsToolAllowedAsync(
                conversationId, 
                llmResponse.ToolName);
            
            if (!isAllowed)
            {
                return ChatResponse.Error("当前状态不允许此操作");
            }
            
            var result = await _toolOrchestrator.ValidateAndExecuteToolAsync(
                llmResponse.ToolCall,
                conversationId,
                projectId);
            
            if (!result.IsSuccess)
            {
                return ChatResponse.Error(result.ErrorMessage);
            }
        }
        
        // 4. 正常响应
        return ChatResponse.Success(responseText);
    }
}
```
